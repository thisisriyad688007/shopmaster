# 📱 Shop Master - Universal Phone Diagnostic & Finance Lock Inspector

**Shop Master** হলো মোবাইল শপ, এক্সচেঞ্জ স্টোর এবং টেকনিশিয়ানদের জন্য তৈরি একটি অল-ইন-ওয়ান হার্ডওয়্যার ডায়াগনস্টিক ও অডিট সফটওয়্যার। এটি ক্যাবল দিয়ে পিসিতে কানেক্ট করা মাত্রই যেকোনো **অ্যান্ড্রয়েড (Xiaomi, Samsung, Vivo, Oppo, Realme, Infinix ইত্যাদি)** অথবা **আইফোন (iOS)** স্বয়ংক্রিয়ভাবে ডিটেক্ট করে। 

3uTools-এর পরিচিত ও ক্ল্যাসিক ইন্টারফেসে তৈরি এই টুলটির মাধ্যমে সেকেন্ড-হ্যান্ড ফোন কেনাবেচার সময় ফোনটির আসল অবস্থা, পার্টস পরিবর্তন এবং কিস্তি/লোন লকের ঝুঁকি তৎক্ষণাৎ শনাক্ত করা যায়।

---

## 🚀 প্রধান ফিচারসমূহ (Key Features)

- **⚡ অটো প্লাগ অ্যান্ড প্লে ডিটেকশন:** ক্যাবল কানেক্ট করার সাথে সাথেই ব্র্যান্ড, সঠিক মডেল, সিরিয়াল নম্বর, IMEI এবং ফার্মওয়্যার ইনফো ডিসপ্লে করে।
- **⚠️ কিস্তি ও ফাইন্যান্স লক ডিটেক্টর (Anti-Fraud EMI Scanner):**
  - **Samsung Knox Guard:** কার্নেল লেভেলে `KG Bit` স্ট্যাটাস চেক করে কিস্তি খেলাপি লক শনাক্ত করে।
  - **গ্লোবাল ও লোকাল লোন অ্যাপস:** PayJoy, Trustonic, DMI Finance, Bajaj Finserv, Snapmint, Cloud DPC (MDM) সহ বিভিন্ন ফাইন্যান্স কন্ট্রোলার স্ক্যান করে ক্লিন নাকি লকড তা বড় অ্যালার্টে দেখায়।
- **🔋 ব্যাটারি ডায়াগনস্টিক ও সাইকেল কাউন্ট:** ফোনটি সর্বমোট কতবার চার্জ দেওয়া হয়েছে (Battery Cycle Count) এবং ব্যাটারির হেলথ স্ট্যাটাস রিয়েল-টাইমে প্রদর্শন করে।
- **🖥️ ডিসপ্লে ও স্ক্রিন ইন্টিগ্রিটি:** অরিজিনাল ফ্যাক্টরি ডিসপ্লে প্যানেল নাকি কপি/রিপ্লেসড স্ক্রিন লাগানো হয়েছে তার প্রাথমিক ওয়ার্নিং প্রদান করে।
- **🛡️ বুটলোডার ও সিকিউরিটি স্ট্যাটাস:** ফোন রুট করা, বুটলোডার আনলকড নাকি Knox ট্রিপড (`0x1`) তা চেক করে।
- **📋 3uTools ভেরিফিকেশন রিপোর্ট:** 3uTools-এর মতো একটি সিঙ্গেল ক্লিকে পূর্ণাঙ্গ হার্ডওয়্যার টেস্টিং ও স্কোর রিপোর্ট দেখার সুবিধা।

## 🛠️ টেকনিক্যাল স্ট্যাক (Tech Stack)

- **GUI Framework:** PyQt6 (3uTools Classic Theme)
- **Core Engine:** Python 3.11+
- **Android Interface:** Pure Python ADB & Google Platform Tools
- **iOS Interface:** libimobiledevice / pymobiledevice3 bindings
- **Build System:** PyInstaller with Automated GitHub Actions CI/CD (Windows `.exe`)

---

## 📦 যেভাবে উইন্ডোজ `.exe` বিল্ড করবেন (Build via GitHub Actions)

১. এই রিপোজিটরিটি আপনার GitHub অ্যাকাউন্টে পুশ/আপলোড করুন।  
২. GitHub-এর **Actions** ট্যাবে যান।  
৩. দেখতে পাবেন `Build Universal 3uTools Master Windows EXE` অটোমেটিক রান হচ্ছে।  
৪. বিল্ড সম্পন্ন হলে **Artifacts** সেকশন থেকে জিপ ফাইলটি ডাউনলোড করে আনজিপ করুন।  
৫. কোনো প্রকার পাইথন ইনস্টলেশন ছাড়াই সরাসরি `ShopMaster.exe` রান করুন।

## ⚠️ ব্যবহারের শর্তাবলী (Prerequisites for Phone)

- **Android:** ফোনে ডেভেলপার অপশন থেকে **USB Debugging** অন থাকতে হবে এবং পিসি কানেক্ট করে স্ক্রিন থেকে *'Always allow'* প্রেস করতে হবে।
- **iPhone:** পিসিতে ক্যাবল লাগিয়ে ফোনে *'Trust This Computer'* প্রেস করে পাসকোড দিতে হবে।
